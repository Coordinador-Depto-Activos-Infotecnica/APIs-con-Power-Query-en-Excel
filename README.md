# APIs con Power Query en Excel

Repositorio dedicado a compartir códigos, ejemplos y soluciones prácticas para conectar APIs con Power Query en Excel.

## 🎯 Objetivo

Compartir conocimiento y soluciones que puedan ser utilizadas por analistas, desarrolladores, profesionales y empresas para automatizar la obtención y transformación de datos.

La intención es que estos códigos sirvan como referencia para aprender, experimentar y desarrollar nuevas soluciones.

## 📚 ¿Qué encontrarás aquí?

- Conexiones a APIs REST
- Códigos en Power Query M
- Manejo de JSON
- Autenticación con APIs
- Paginación
- Transformación de datos
- Automatización de consultas
- Ejemplos aplicados a Excel

## 🚀 Cómo utilizar los códigos

Cada ejemplo incluirá el código de Power Query y, cuando sea necesario, instrucciones para configurarlo en Excel.

> ⚠️ Nunca publiques API Keys, tokens, contraseñas o credenciales reales en este repositorio.
